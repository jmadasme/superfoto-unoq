# rec/ — video explicativo

Este directorio contiene el video asciinema de **Superfoto: muchas fotos, una imagen mejor** y el reproductor
que se usa en la página del proyecto.

- `superfoto-unoq.cast`: grabación original (asciicast v2).
- `superfoto-unoq.cast.js`: los eventos embebidos para el reproductor inline.
- `player.js` / `player.css`: reproductor reutilizable.

Duración: 2:41. Los fragmentos de código son reales y
corresponden a los archivos y líneas indicados en el video.
